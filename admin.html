Configuración en js/config.js

  1. GOOGLE_SHEET_ID — ID del spreadsheet
  2. GOOGLE_API_KEY — API Key (lectura pública)
  3. APPS_SCRIPT_URL — URL de la app web
  4. APPS_SCRIPT_TOKEN — mismo token que en apps-script/Codigo.gs

Cómo publicar para todos

  1. Cargá equipos, fixture, resultados y jugadores aquí.
  2. Andá a Exportar → descargá torneo.json.
  3. Reemplazá el archivo data/torneo.json del proyecto.
  4. Subí/publicá el sitio (GitHub Pages) para que la comunidad vea los datos.

Google Sheets se conectará después. Mientras tanto este flujo ya sirve para el evento.
